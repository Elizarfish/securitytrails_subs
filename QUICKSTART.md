# 🚀 Быстрый старт

## Минимальная установка (3 простых шага)

### 1️⃣ Установите зависимости

```bash
# Корневая директория
npm install

# Сервер
cd server && npm install && cd ..

# Клиент
cd client && npm install && cd ..
```

### 2️⃣ Настройте окружение

```bash
cd server
cp .env.example .env
cd ..
```

Откройте `server/.env` и замените `your_jwt_secret_key_here` на любую секретную строку.

### 3️⃣ Запустите приложение

```bash
npm run dev
```

✅ Готово! Откройте http://localhost:3000

## 📝 Тестовые действия

1. **Зарегистрируйтесь** - создайте новый аккаунт
2. **Просмотрите студии** - перейдите в раздел "Студии"
3. **Забронируйте** - выберите студию, дату и время
4. **Проверьте** - посмотрите "Мои бронирования"

## 🎯 Готовые студии

При первом запуске автоматически создаются 4 фотостудии:
- Студия "Светлая" - 2500 ₽/час
- Студия "Креатив" - 3000 ₽/час  
- Студия "Лофт" - 3500 ₽/час
- Студия "Винтаж" - 2800 ₽/час

## 🔧 Если что-то не работает

```bash
# Очистить кэш и переустановить
rm -rf node_modules package-lock.json
npm install
cd server && npm install && cd ..
cd client && npm install && cd ..

# Запустить снова
npm run dev
```

## 📱 Доступ

- **API**: http://localhost:5000/api
- **Health Check**: http://localhost:5000/api/health
