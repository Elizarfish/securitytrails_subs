# 📸 Приложение для бронирования фотостудии

Полнофункциональное веб-приложение для бронирования фотостудий с современным интерфейсом и админ-панелью.

## 🚀 Возможности

### Для пользователей:
- 🔐 Регистрация и авторизация
- 🏢 Просмотр доступных фотостудий
- 📅 Бронирование студий с выбором даты и времени
- 📋 Просмотр своих бронирований
- ❌ Отмена бронирований
- 💰 Прозрачное ценообразование

### Для администраторов:
- 👥 Управление всеми бронированиями
- ✅ Изменение статусов бронирований
- 🏢 Управление студиями
- 📊 Просмотр статистики

## 🛠 Технологии

### Backend:
- **Node.js** + **Express.js** - серверная часть
- **MongoDB** + **Mongoose** - база данных
- **JWT** - аутентификация
- **bcryptjs** - хеширование паролей
- **express-validator** - валидация данных

### Frontend:
- **React** + **TypeScript** - клиентская часть
- **React Router** - маршрутизация
- **React Calendar** - календарь бронирований
- **Axios** - HTTP клиент
- **CSS3** - стилизация

## 📦 Установка и запуск

### Предварительные требования:
- Node.js (версия 14 или выше)

### 1. Установка зависимостей:
```bash
# Установка зависимостей для сервера и клиента
npm run install-all
```

### 2. Запуск приложения:
```bash
# Запуск сервера и клиента одновременно
npm run dev

# Или по отдельности:
npm run server  # Запуск только сервера (порт 3001)
npm run client  # Запуск только клиента (порт 3000)
```

### 3. Открытие приложения:
Откройте браузер и перейдите по адресу: `http://localhost:3000`

### 4. Демо-страница:
Откройте файл `demo.html` в браузере для просмотра демонстрации возможностей приложения.

## 📱 Использование

## 🔧 API Endpoints

### Аутентификация:
- `POST /api/auth/register` - Регистрация
- `POST /api/auth/login` - Вход
- `GET /api/auth/me` - Получение текущего пользователя

### Студии:
- `GET /api/studio` - Получение всех студий
- `GET /api/studio/:id` - Получение студии по ID
- `POST /api/studio` - Создание студии (админ)
- `PUT /api/studio/:id` - Обновление студии (админ)
- `DELETE /api/studio/:id` - Удаление студии (админ)

### Бронирования:
- `GET /api/bookings/my-bookings` - Мои бронирования
- `GET /api/bookings/all` - Все бронирования (админ)
- `POST /api/bookings/create` - Создание бронирования
- `PATCH /api/bookings/:id/status` - Изменение статуса
- `DELETE /api/bookings/:id` - Отмена бронирования
- `GET /api/bookings/available-slots` - Доступные слоты

## 🚀 Развертывание

### Локальное развертывание:
1. Установите MongoDB локально
2. Следуйте инструкциям по установке выше

### Облачное развертывание:
1. Используйте MongoDB Atlas для базы данных
2. Обновите `MONGODB_URI` в `.env`
3. Разверните на Heroku, Vercel или другом хостинге
