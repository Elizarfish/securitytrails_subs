# 📸 Приложение для бронирования фотостудий

Современное веб-приложение для бронирования фотостудий с удобным интерфейсом и полным функционалом управления бронированиями.

## 🚀 Функциональность

### Для клиентов:
- 📋 Просмотр доступных фотостудий
- 📅 Проверка доступности в реальном времени
- 🎯 Простое бронирование с выбором даты и времени
- 💰 Автоматический расчет стоимости
- 📱 Поиск своих бронирований по email
- ✅ Подтверждение бронирования

### Для студий:
- 🏢 Управление информацией о студии
- 💡 Указание удобств и оборудования
- 💵 Настройка цен за час
- 📊 Просмотр всех бронирований

## 🛠 Технологический стек

### Backend:
- **Node.js** + **Express.js** - серверная часть
- **SQLite** - база данных
- **JWT** - аутентификация (готово к расширению)
- **Express Validator** - валидация данных
- **CORS** - поддержка кросс-доменных запросов

### Frontend:
- **React 18** - пользовательский интерфейс
- **React Router** - маршрутизация
- **Axios** - HTTP клиент
- **React Toastify** - уведомления
- **Lucide React** - иконки
- **CSS3** - стилизация с градиентами и анимациями

## 📦 Установка и запуск

### Предварительные требования:
- Node.js 16+ 
- npm или yarn

### Шаги установки:

1. **Клонируйте репозиторий:**
   \`\`\`bash
   git clone <repository-url>
   cd photo-studio-booking
   \`\`\`

2. **Установите зависимости:**
   \`\`\`bash
   # Установка зависимостей сервера
   npm install
   
   # Установка зависимостей клиента
   cd client && npm install && cd ..
   \`\`\`

3. **Запустите приложение:**
   
   **Вариант 1: Запуск в режиме разработки (сервер + клиент)**
   \`\`\`bash
   npm run dev
   \`\`\`
   
   **Вариант 2: Запуск только сервера**
   \`\`\`bash
   npm run server
   \`\`\`
   
   **Вариант 3: Сборка и запуск в продакшене**
   \`\`\`bash
   npm run build
   npm start
   \`\`\`

4. **Откройте приложение:**
   - Режим разработки: http://localhost:3000
   - Продакшен: http://localhost:5000

## 🗄 Структура базы данных

### Таблица `studios`:
- `id` - уникальный идентификатор
- `name` - название студии
- `description` - описание
- `address` - адрес
- `price_per_hour` - цена за час
- `capacity` - вместимость
- `amenities` - удобства (строка через запятую)
- `image_url` - ссылка на изображение

### Таблица `bookings`:
- `id` - уникальный идентификатор
- `studio_id` - ссылка на студию
- `user_name` - имя клиента
- `user_email` - email клиента
- `user_phone` - телефон клиента
- `start_datetime` - дата и время начала
- `end_datetime` - дата и время окончания
- `total_price` - общая стоимость
- `status` - статус (pending/confirmed/cancelled/completed)
- `notes` - дополнительные заметки

### Таблица `users`:
- `id` - уникальный идентификатор
- `name` - имя пользователя
- `email` - email (уникальный)
- `phone` - телефон
- `created_at` - дата создания

## 🔧 API Endpoints

### Студии:
- `GET /api/studios` - получить все студии
- `GET /api/studios/:id` - получить студию по ID
- `GET /api/studios/:id/availability?date=YYYY-MM-DD` - проверить доступность

### Бронирования:
- `GET /api/bookings` - получить все бронирования
- `GET /api/bookings/:id` - получить бронирование по ID
- `POST /api/bookings` - создать бронирование
- `PATCH /api/bookings/:id/status` - обновить статус
- `DELETE /api/bookings/:id` - удалить бронирование

### Пользователи:
- `GET /api/users` - получить всех пользователей
- `GET /api/users/by-email/:email` - найти пользователя по email
- `GET /api/users/:email/bookings` - получить бронирования пользователя
- `POST /api/users` - создать/обновить пользователя

## 📝 Примеры использования

### Создание бронирования:
\`\`\`javascript
const bookingData = {
  studio_id: 1,
  user_name: "Иван Иванов",
  user_email: "ivan@example.com",
  user_phone: "+7 999 123-45-67",
  start_datetime: "2024-01-15T10:00:00.000Z",
  end_datetime: "2024-01-15T14:00:00.000Z",
  notes: "Портретная съемка"
};

const response = await fetch('/api/bookings', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify(bookingData)
});
\`\`\`

### Проверка доступности:
\`\`\`javascript
const availability = await fetch('/api/studios/1/availability?date=2024-01-15');
const data = await availability.json();
console.log(data.availableSlots); // Доступные временные слоты
\`\`\`
