# 📸 Приложение для Бронирования Фотостудий

Современное веб-приложение для онлайн бронирования фотостудий с удобным интерфейсом и полным функционалом управления бронированиями.

## ✨ Возможности

- 🎯 **Просмотр студий** - Каталог доступных фотостудий с подробной информацией
- 📅 **Бронирование** - Выбор даты и времени с проверкой доступности в реальном времени
- 👤 **Регистрация/Вход** - Система аутентификации пользователей
- 📋 **Мои бронирования** - Управление своими бронированиями
- 💰 **Автоматический расчет стоимости** - Прозрачное ценообразование
- 🔒 **Безопасность** - JWT токены и хеширование паролей
- 📱 **Адаптивный дизайн** - Работает на всех устройствах

## 🛠 Технологии

### Backend
- **Node.js** + **Express** - Серверная часть
- **SQLite** - База данных
- **JWT** - Аутентификация
- **bcryptjs** - Хеширование паролей

### Frontend
- **React** - UI библиотека
- **React Router** - Маршрутизация
- **date-fns** - Работа с датами
- **CSS3** - Современные стили

## 📦 Установка

### Требования
- Node.js (версия 14 или выше)
- npm или yarn

### Шаг 1: Клонирование репозитория

```bash
git clone <your-repo-url>
cd photo-studio-booking
```

### Шаг 2: Установка зависимостей

```bash
# Установка зависимостей для всего проекта
npm install

# Установка зависимостей для сервера
cd server
npm install

# Установка зависимостей для клиента
cd ../client
npm install
cd ..
```

### Шаг 3: Настройка окружения

Создайте файл `.env` в папке `server`:

```bash
cd server
cp .env.example .env
```

Отредактируйте `.env` файл:
```
PORT=5000
JWT_SECRET=your_strong_secret_key_here
NODE_ENV=development
```

### Шаг 4: Запуск приложения

#### Вариант 1: Запуск в режиме разработки (рекомендуется)

Из корневой директории проекта:

```bash
npm run dev
```

Это запустит одновременно сервер (порт 5000) и клиент (порт 3000).

#### Вариант 2: Раздельный запуск

**Терминал 1 - Сервер:**
```bash
cd server
npm start
```

**Терминал 2 - Клиент:**
```bash
cd client
npm start
```

### Шаг 5: Открытие приложения

Откройте браузер и перейдите по адресу:
```
http://localhost:3000
```

API сервера доступен по адресу:
```
http://localhost:5000/api
```

## 🔐 API Endpoints

### Аутентификация
- `POST /api/auth/register` - Регистрация пользователя
- `POST /api/auth/login` - Вход пользователя
- `GET /api/auth/me` - Получить текущего пользователя

### Студии
- `GET /api/studios` - Получить все студии
- `GET /api/studios/:id` - Получить студию по ID
- `POST /api/studios` - Создать студию (требуется авторизация)

### Бронирования
- `GET /api/bookings/my-bookings` - Получить бронирования пользователя
- `GET /api/bookings/studio/:studioId/date/:date` - Получить бронирования для студии и даты
- `POST /api/bookings` - Создать бронирование
- `PATCH /api/bookings/:id/cancel` - Отменить бронирование

## 💡 Использование

### 1. Регистрация
1. Нажмите "Регистрация" в шапке сайта
2. Заполните форму регистрации
3. Вы будете автоматически авторизованы

### 2. Просмотр студий
1. Перейдите в раздел "Студии"
2. Просмотрите доступные фотостудии
3. Нажмите на студию для подробной информации

### 3. Бронирование
1. Выберите студию
2. Выберите дату и время
3. Добавьте примечания (опционально)
4. Нажмите "Забронировать"
5. Система автоматически рассчитает стоимость

### 4. Управление бронированиями
1. Перейдите в "Мои бронирования"
2. Просмотрите все свои бронирования
3. Отмените бронирование при необходимости

## 🐛 Устранение неполадок

### Порт уже используется
Если порт 3000 или 5000 занят, измените порт в соответствующих файлах:
- Client: изменить в `client/package.json`
- Server: изменить в `server/.env`

### База данных не создается
Убедитесь, что у вас есть права на запись в папку `server/`

### Проблемы с зависимостями
Попробуйте очистить кэш и переустановить:
```bash
rm -rf node_modules package-lock.json
npm install
```
