# Photo Studio Booking App

Приложение для бронирования фотостудий с веб-интерфейсом и админ-панелью.

## Функционал

- **Каталог студий** - просмотр доступных фотостудий с описанием и ценами
- **Система бронирования** - выбор даты и времени, расчет стоимости
- **Аутентификация пользователей** - регистрация и вход в систему
- **Админ-панель** - управление студиями и бронированиями
- **Адаптивный дизайн** - работает на всех устройствах

## Технологии

### Backend
- **Node.js** + **Express.js** - серверная часть
- **Sequelize ORM** - работа с базой данных
- **SQLite** - база данных
- **JWT** - аутентификация
- **bcrypt** - хэширование паролей

### Frontend
- **React 18** - пользовательский интерфейс
- **Vite** - инструмент сборки
- **React Router** - навигация
- **CSS3** - стилизация

## Установка и запуск

### 1. Клонирование репозитория
```bash
git clone <repository-url>
cd photo-studio-booking
```

### 2. Установка зависимостей

#### Backend
```bash
cd backend
npm install
```

#### Frontend
```bash
cd frontend
npm install
```

### 3. Запуск приложения

#### Backend (терминал 1)
```bash
cd backend
npm start
```
Сервер запустится на http://localhost:5000

#### Frontend (терминал 2)
```bash
cd frontend
npm run dev
```
Приложение откроется на http://localhost:3000

## Использование

### Для пользователей
1. Зарегистрируйтесь или войдите в систему
2. Выберите подходящую студию из каталога
3. Укажите дату и время бронирования
4. Подтвердите бронирование

### Для администраторов
- Войдите с демо-аккаунтом: `admin@photostudio.com` / `admin123`
- Перейдите в раздел "Админ" для управления студиями и бронированиями
- Подтверждайте или отменяйте бронирования пользователей

## API Эндпоинты

### Студии
- `GET /api/studios` - получить все студии
- `GET /api/studios/:id` - получить студию по ID

### Бронирования
- `GET /api/bookings` - получить все бронирования
- `POST /api/bookings` - создать новое бронирование
