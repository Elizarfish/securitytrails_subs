# 📸 Приложение для бронирования фотостудии - Сводка проекта

## ✅ Что создано

### 🏗 Архитектура приложения
- **Full-stack приложение** с разделением на фронтенд и бэкенд
- **RESTful API** для управления данными
- **Файловая система** для хранения данных (без необходимости в MongoDB)
- **JWT аутентификация** для безопасности

### 🎨 Frontend (React + TypeScript)
- **Современный UI** с адаптивным дизайном
- **Система аутентификации** (регистрация/вход)
- **Календарь бронирований** с выбором даты и времени
- **Управление бронированиями** для пользователей
- **Админ-панель** для администраторов
- **TypeScript** для типобезопасности

### ⚙️ Backend (Node.js + Express)
- **API сервер** с Express.js
- **Маршруты для аутентификации** (регистрация, вход, профиль)
- **Маршруты для студий** (просмотр, управление)
- **Маршруты для бронирований** (создание, просмотр, управление)
- **Middleware** для аутентификации и авторизации
- **Валидация данных** и обработка ошибок

### 🗄️ Система данных
- **JSON файлы** для хранения данных (users.json, studios.json, bookings.json)
- **Автоматическая инициализация** тестовых данных
- **Предустановленные студии** с полной информацией
- **Тестовые пользователи** (админ и обычный пользователь)

## 🚀 Возможности приложения

### Для пользователей:
1. **Регистрация и авторизация** с валидацией данных
2. **Просмотр доступных студий** с детальной информацией
3. **Бронирование студий** с выбором даты, времени и продолжительности
4. **Просмотр своих бронирований** с возможностью отмены
5. **Добавление заметок** и особых пожеланий к бронированию

### Для администраторов:
1. **Управление всеми бронированиями** в системе
2. **Изменение статусов бронирований** (ожидает, подтверждено, отменено, завершено)
3. **Просмотр информации о клиентах** (имя, email, телефон)
4. **Управление студиями** (просмотр, редактирование)

## 🛠 Технологический стек

### Frontend:
- **React 18** - библиотека для создания пользовательского интерфейса
- **TypeScript** - типизированный JavaScript
- **React Router** - маршрутизация в приложении
- **React Calendar** - компонент календаря для выбора дат
- **Axios** - HTTP клиент для API запросов
- **CSS3** - стилизация с современными возможностями

### Backend:
- **Node.js** - серверная платформа
- **Express.js** - веб-фреймворк
- **JWT** - JSON Web Tokens для аутентификации
- **bcryptjs** - хеширование паролей
- **express-validator** - валидация входящих данных
- **CORS** - настройка кросс-доменных запросов

### 2. **Пользовательский опыт**
- Интуитивный интерфейс

### 3. **Функциональность**
- Проверка конфликтов времени при бронировании
- Автоматический расчет стоимости
- Управление статусами бронирований
- Детальная информация о студиях

### 4. **Масштабируемость**
- Модульная архитектура
